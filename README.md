# Simulador-de-entrenamiento-Pokemon
Pokémon Simulator 

Simulador de entrenamiento y batallas Pokémon desarrollado en **Python** como práctica de Programación Orientada a Objetos.  
El proyecto implementa conceptos de **herencia**, **métodos de clase**, **métodos estáticos** y **manejo de excepciones**.

Instalación
1. Descarga el archivo `.zip` del repositorio.  
2. Descomprime el contenido en tu computadora.  
3. Asegúrate de tener instalado **Python 3.10 o superior**.  
   - Para verificar, ejecuta en la terminal:
     ```bash
     python --version

Estructura del proyecto
Pokemon_simulator/
├── main.py          # Menú interactivo
└── clases/
└── pokemon.py   # Definición de clases y lógica

Ejecución
1. Abre una terminal en la carpeta raíz `Pokemon_simulator`.  
2. Ejecuta el programa con:
   ```bash
   python main.py
